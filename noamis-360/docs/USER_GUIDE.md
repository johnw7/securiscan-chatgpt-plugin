# Guide utilisateur

## Première connexion

1. Ouvrez le lien d'activation reçu de votre administrateur et choisissez votre mot de passe (12 caractères minimum).
2. Administrateurs : scannez le QR code avec une application d'authentification (Google Authenticator, Microsoft Authenticator, 1Password…) et saisissez le code. Ce code sera demandé à chaque connexion.

## Équipe NOAMIS

- **Tableau de bord** : missions actives, pipeline pondéré, CA facturé, encours, tâches, agenda, retards.
- **Clients & contacts** : fiche client avec contacts, missions, documents, finance, notes internes (jamais visibles du client) et historique.
- **Pipeline** : déplacez une opportunité d'étape avec la liste déroulante ; « Convertir en client » crée la fiche. Les demandes du diagnostic public arrivent en « Nouveau ».
- **Missions** : avancement, équipe (mission confidentielle = accès restreint), tâches, documents. Le client voit les missions marquées « visibles ».
- **Audit** : créez l'audit, remplissez le questionnaire sur place (sauvegarde automatique, même hors connexion), ajoutez constats et photos, cotez les risques (justification obligatoire), proposez des recommandations, puis **validez** : les résultats cessent d'être indicatifs. « Déposer dans l'espace client » publie le rapport PDF.
- **Projets AMOA** : suivez les 8 étapes, rédigez le cahier des charges, saisissez offres et critères pondérés, notez sur 10 : le classement se calcule seul ; exportez en PDF ou Excel ; consignez réunions, décisions et réserves ; clôturez (impossible avec une réserve ouverte).
- **Intelligence** : déclarez des sources (fiabilité A à F), collectez les flux autorisés, retenez des contenus, créez une fiche (ou un brouillon IA), vérifiez, **validez**, puis diffusez aux clients choisis.
- **Documents** : importez, versionnez, partagez avec le client, ou créez un lien temporaire pour un tiers (jamais pour un rapport de sûreté).
- **Finance** : devis (lignes du catalogue, remises, TVA), envoi au portail, conversion en facture, **émission par un administrateur** (numéro définitif, document figé), règlements, relances, avoirs, export comptable.
- **Portail clients** : messagerie, demandes de validation.

## Clients (NOAMIS CONNECT)

Accueil, missions et échéances, documents (téléchargement, dépôt de pièces), validations, devis à accepter ou refuser en ligne, factures, messagerie, recommandations et veille, historique.

## Diagnostic public (NOAMIS PROTECT)

Accessible sans compte sur `/diagnostic` : questionnaire, résultat indicatif, synthèse PDF, demande de rappel avec consentement. Ce n'est pas un audit de sûreté.
