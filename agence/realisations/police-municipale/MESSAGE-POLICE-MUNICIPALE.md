# Message aux polices municipales

## Version e-mail

**Objet :** Vos supports de prévention, réalisés gracieusement

Madame, Monsieur,

Comme convenu, voici les créations que j'ai réalisées pour vous :

- la campagne « Grandir en sécurité » : 7 affiches A4 pour sensibiliser les enfants (traverser, casque, trottinette, inconnus, internet, le 17, la confiance envers les agents) ;
- une seconde campagne de 6 affiches : tranquillité vacances, trottinettes, abords des écoles, faux démarcheurs, dépôts sauvages, téléphone au volant ;
- la vidéo « Le permis vélo », avec dialogues, au format vertical pour les réseaux sociaux et les interventions en classe.

Tous ces supports peuvent être adaptés au nom de votre commune.

Je prépare actuellement le concours de policier municipal pour 2027. En attendant de vous rejoindre sur le terrain, je souhaite mettre mes compétences en communication au service de la police municipale, gracieusement.

Si vous le souhaitez, je peux vous préparer tous les thèmes de prévention qui vous sont utiles, sous différents formats : affiches, flyers, vidéos, publications pour les réseaux sociaux, supports d'intervention en milieu scolaire ou kakémonos pour vos stands.

C'est pour moi un honneur de servir de cette façon.

Je reste à votre disposition pour échanger.

Bien respectueusement,
