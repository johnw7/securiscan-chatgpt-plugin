# Campagne de sensibilisation : Police municipale

Proposition de campagne créée par E-DUST Solutions. Document de démonstration non officiel : chaque affiche porte cette mention.

## Direction artistique
Couleurs reprises de l'écusson : bleu marine `#16226b`, bleu `#2b3a9c`, rouge `#e1131b`, argent `#a7adb8`, blanc. Titres en Barlow Condensed 900, textes en Inter.

## Affiches (1080×1350, `affiches/`)
1. Proches de vous. Chaque jour. (proximité)
2. Vous partez ? Nous veillons. (Opération tranquillité vacances)
3. Ce qui se voit se vole. (vols dans les véhicules)
4. Un uniforme ne suffit pas. (faux agents)
5. 30 : abords des écoles
6. 17 / 112 : numéros d'urgence
7. Le calme, ça se partage. (calme nocturne)
8. Un doute ? Signalez-le.

## Planches
- `planche-galerie.jpg` : les 8 affiches
- `planche-situation.jpg` : abribus, affichage A3, uniforme avant / après, plan de diffusion

## Uniforme
Dans `img/uniforme-logo-remplace.jpg`, l'écusson fourni remplace celui d'origine sur la manche. `agent-face.png` et `agent-dos.png` sont les détourages utilisés dans les affiches.
