# Site vitrine E-DUST Solutions

Site statique (HTML, CSS, JavaScript), sans dépendance ni compilation.

## Mettre le site en ligne
Envoyez **tout le contenu de ce dossier** (index.html, styles.css, script.js, assets/, telechargements/) à la racine de votre hébergement (OVH, Hostinger, o2switch, Netlify, Vercel…), par FTP ou par glisser-déposer.

## Modifier les contenus
- Textes : `index.html`
- Réalisations et vidéos : listes `WORKS` et `REELS` en haut de `script.js`
- Couleurs : variables en haut de `styles.css`
- Numéro WhatsApp / téléphone : rechercher `33613249680` et `+33 6 13 24 96 80`

Le formulaire de contact ouvre WhatsApp avec le message prérempli : aucun serveur n'est nécessaire.
